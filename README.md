## Як запустити

**IntelliJ IDEA:** File → Open → папка `Laba_7_Java`. Якщо IDEA попросить JDK, натисни *Setup SDK* → *Download JDK* (підійде будь-яка версія від 8).
Для кожного завдання вже є конфігурація запуску — обери її у списку вгорі праворуч і натисни ▶.

**Командний рядок** (з кореня проєкту):

```
javac -encoding UTF-8 -d out src/task1/*.java src/task2/*.java
java -cp out task1.TrafficFrame
```

Код сумісний з Java 8 і новішими.
